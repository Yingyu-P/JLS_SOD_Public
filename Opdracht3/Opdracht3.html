Onderzoek Webontwikkeling

1.Waarom heet de eerste pagina van een website vaak index.html?

Omdat het meestal een standaard startpagina van een website is.

2.Met welke HTML-versie werken we tegenwoordig?

We werken tegenwoordig met HTML5.

3.Met welke CSS-versie werken we tegenwoordig?

We werken tegenwoordig met CSS3.

4.Hoe kan het dat een website er net iets anders uitziet in verschillende browsers, zoals Edge, Chrome, Firefox en Opera?

Doordat elke bronwser een eigen weergave-engine gebruikt kan het anders verwerken en weergeven.

5.Welke browser is momenteel het populairst?

Google Chrome is momenteel wereldwijd het populairst.

6.Waar staat de afkorting HTML voor?

HTML staat voor HyperText Markup Language.

7.Waar staat de afkorting CSS voor?

CSS staat voor Cascading Style Sheets.

8.Wat is het verschil tussen HTML en CSS?

HTML is de structuur en de inhoud van een website en CSS is de opmaak en hoe het eruit ziet van een website.

9.Wat is het doel van een webbrowser?

Met een webbrowser kan je een website openen en bekijken. De browser verwerkt onderandere HTML en CSS en zet deze om in een webpagina. Dus opzoeken, ophalen en weergeven van informaties op het internet.

10.Noem drie populaire code-editors die gebruikt worden voor webontwikkeling.

1. Visual Studio Code

2. Sublime Text

3. WebStorm

11.Wat is het verschil tussen een statische website en een dynamische website?

Een statische website toont pagina's waarvan de inhoud dezelfde blijven en een dynamische website bouwt per bezoeker een pagina op basis van bijvoorbeeld database en server

12.Waarom is het belangrijk om je HTML-code netjes en correct op te bouwen?

Het zorgt dan ervoor dar browser de pagina foutloos tonen en dat zoekmachine de inhoud goed begrijpen.
